# AustriQ Individual CRM · Ideen

Eigenständiges Frontend-Modul. Ideen-Inbox, Projektzuordnung und eine kreative lokale Arbeitsfläche; keine Drittanbieter-Verarbeitung.

Die API `render(slot, context)` stellt eine vollständige Arbeitsansicht (`center`) und sieben verschiedene kompakte Platzansichten bereit. Jedes Modul hat eine eigene Version, eine deklarative Fähigkeitentabelle und isolierte Node-Tests. Der CRM-Host verwaltet die Slots und autorisiert alle Aktionen. Keine externen npm-Abhängigkeiten; keine echten Kundeninformationen oder Zugangsdaten.
